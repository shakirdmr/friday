# Memory navigation icons

Four original SVG illustrations drawn for this project; no external icon pack or image generation is used for this set.

| Asset | Meaning | Design |
| --- | --- | --- |
| `public/icons/home.svg` | Home | Amber-roofed house with a teal arched door |
| `public/icons/memories.svg` | Memories | Coral photo journal with a golden bookmark |
| `public/icons/discoveries.svg` | Discoveries | Green discovery lens with a golden spark |
| `public/icons/you.svg` | You | Pip's blue face and golden leaf |

Each uses a 72 × 72 canvas, warm white sticker edging, rounded forms, and shallow shading. Mobile navigation renders them at 32 CSS pixels in a 76-pixel bar, plus device safe-area space. The same assets appear in the desktop sidebar and matching home cards.

The assets are self-contained and contain no scripts, fonts, external references, or embedded raster images. The React wrapper marks them decorative because their buttons already have visible text labels. The selected tab has a raised icon and a pale mint background; keyboard focus remains visible, and motion follows the app's reduced-motion setting.
