# Companion-world artwork, version 2

Generated using the built-in image_gen tool. The user's Finch screenshot was supplied as a style and composition reference for the room. The character cutout was then derived from that generated room. Existing SVG artwork remains available for the landing page.

Assets:
- `public/art/pip-room-v2.png` — original generated room.
- `public/art/pip-room-v2.webp` — WebP encoding used by the app.
- `public/art/pip-character-v2.png` — original transparent character.
- `public/art/pip-character-v2.webp` — WebP encoding with alpha, used in the app's profile and companion introduction.

The artwork contains no interface text. Navigation, progress, cards, and interactions are real HTML, React, and CSS. WebP conversion preserves the artwork and transparency.
